Overview

Many labs have several capable PCs and no simple way to share them. ChemCompute packages the whole arrangement into a Windows installer: choose Controller, Compute node or Both, and a machine registers into a private, invite-only compute pool.

The console exposes node CPU, RAM and GPU capacity, lets owners set contribution budgets, and runs GROMACS jobs through a queue that uploads step packages, executes them on a chosen node, and streams results back. Gaussian is supported through a private vendor-media deployment path.

Highlights

01

One installer, three roles

Bundles Python and Tk — no separate runtime. Target machines need nothing else installed.

02

Invite-only joining

The controller exports a single-use invite; a new machine installs and registers with that code.

03

Contribution budgets

Owners set CPU core share, memory budget, GPU toggle, or pause new tasks entirely.

04

Verified online upgrades

Downloads from official releases, validates SHA-256, waits for idle tasks, preserves config and results.

Task lifecycle

Upload ZIP→ Preview steps→ Pick resources→ Node executes→ Results returned

The v2 queue supports per-node task isolation, lease recovery after disconnects, and checkpoint-based GROMACS continuation. Package validation blocks directory traversal, links, encrypted archives, dangerous Windows names and CRC errors before anything runs.
