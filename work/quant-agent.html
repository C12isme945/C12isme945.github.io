Overview

Quant Agent is a modular research framework for systematic trading: data providers, strategies, backtesting, risk controls, brokers and agents each have a defined boundary. It is designed to produce evidence, not promises — the default mode is backtest or paper trading, and the live path requires multiple deliberate confirmations.

The v2.1 release added multi-provider data collection (yfinance, AKShare, Alpha Vantage), GUI configuration for LLM providers, news sentiment overlays, and a research loop that can propose strategy-paper promotion without ever granting live eligibility automatically.

Highlights

01

Four strategies, one framework

MA cross, RSI, MACD momentum and Bollinger mean-reversion with shared parameter tuning and search spaces.

02

Risk before returns

Every order passes a risk manager with position, notional, daily-loss and drawdown limits — plus stop-loss and take-profit handling.

03

LLM research, not execution

Agents submit JSON proposals that are converted to orders only through the gateway. They never touch a broker directly.

04

Metrics that matter

Sortino and Calmar ratios, average trade P&L, win/loss streaks, and half-Kelly position sizing.

Every order follows the same path

Strategy→ Decision agent→ Risk manager→ Approval gate→ Broker adapter→ Audit log

Live submission requires all of: live mode, an explicit enable flag, a disabled kill switch, ALPACA_PAPER=false, a typed risk acknowledgment, a separate order approval, and passing every risk check. Any missing guard stops the order.

A risk statement, not a pitch. This project provides research infrastructure only. It does not offer investment advice or return guarantees. Trading systems lose money, fail on bad data, and behave unexpectedly — the README says this plainly, and the software is built as if it were true.
